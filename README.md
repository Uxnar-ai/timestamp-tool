# 时间戳 ts · 粘一串数字就变成能看懂的时间

> 把日志里的时间戳一行一个粘进来，立刻变成「2026-10-30 06:08:00 周五 + UTC + 2 小时前」。反向也行：给个日期拿回秒和毫秒。

[English](README.en.md) | 中文

## 这是什么

翻日志的时候最烦的就是 `1793311291` 这种数，心里换算不出来它是几分钟前还是几个月前。

这页不做别的，就把这一步做成粘贴即得。每一行先判断是什么：纯数字按位数分——10 位当秒、13 位当毫秒、11/12 位按比例放大、15 位以上截前 13 位（微秒和纳秒都这么处理）；不是数字就当日期解析，`2026-10-30 06:08:00` 和带 `Z` 的 ISO 都认。

输出对每行都列全：本地时间带星期、UTC、相对当前多久（2 小时前 / 3 天前），以及秒和毫秒两种形式。日期那一侧还会把横杠换成斜杠再解一次——这是为了兼容把 `2026-10-30 06:08:00` 当本地时间的老写法，不然它会按 UTC 解析，差 8 小时。

顶部有实时的「现在」，秒和毫秒各一个复制按钮。示例数据按打开那一刻现算，所以永远显示「2 小时前 / 5 分钟前」，不会变成一堆「12 个月前」。

## 功能

- 一行一个，批量转，不用一个个算
- 自动识别 10 位秒 / 13 位毫秒 / 11–12 位 / 微秒 / 纳秒
- 反向转换：日期或 ISO 时间 → 秒 + 毫秒
- 每行都给本地时间（带星期）、UTC、相对时间
- 顶部实时「现在」，秒与毫秒一键复制
- 认不出的行单独标出来，不静默跳过
- 深色/浅色自适应 + 手动切换
